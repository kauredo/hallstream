# Security

To report a vulnerability, use GitHub's private reporting: the Security tab, then "Report a vulnerability". Don't open a public issue.

What counts as security in Hallstream:

- Anything that lets another device or website control the panel, read the OBS password or the YouTube login, or download the data backup. The server listens on 127.0.0.1 unless phone access is on. With phone access on, it requires a PIN.
- Anything that lets a downloaded file, a promo video or an FPB answer run code or write outside the `dados` folder.

You'll get an answer within a week.
