# Amendments after round 7 (apply on top of SYSTEM-R3 and SYSTEM-R4; this file wins)

1. Secondary text on navy is white at 72% (rgba(255,255,255,0.72)), never lavender.
2. Visitor score cell: filled with the visitor accent (awayColor), white numerals, so it reads as its own cell like the home side's kit-red cell. The awayColor default becomes #5C6170 (a dark neutral grey, white text ≥ 6:1). The 6px strips under the emblem tiles are removed on both teams (critics read them as "selected tab" underlines); the score cell now carries the team colour instead. Home: name red #BD1522, score cell kit red #8B2223 (unchanged).
3. Period labels are white everywhere (gold is only the 4+ foul warning, the "24s" label, and the state words).
4. The time-out screen, half-time and full-time all use the SAME team unit as the scoreboard: one row [tile][name][score], same proportions, both teams equal width.
5. Half-time and full-time share one header: a navy tab attached to the top edge of the score block, holding the gold state word (INTERVALO / RESULTADO FINAL) and the competition line under or beside it.
